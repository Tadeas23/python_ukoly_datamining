# Cvičení z datové analýzy

Zde se nacházejí data k analýze. **Obsah této složky neměňte.**

Jednotlivé složky s letopočtem zachycují data pro nastupující žáky prvních ročníků, kteří v daném roce konali přijímací zkoušku.

Složky `prijimaci_rizeni` obsahují data o výsledcích přijímacích zkoušek zájemců o jednotlivé obory včetně informace přijat/nepřijat.

Složky `souhrn_matematiky` obsahují souhrnná data o výsledcích žáků z MAT na ZŠ, u přijímaček, a ve vstupních testech v prvním ročníku.

Složky `detaily_testu` obsahují podrobná data o vstupních testech z MAT (jak úspěšně žáci řešili jednotlivé úlohy a jak uspěli celkově).

**! POZOR !** Ne pro všechny ročníky jsou dostupná všechna data. **! POZOR !**

**! POZOR !** Formát dat v jednotlivých ročnících se může lišit. **! POZOR !**
